# Dhaka Kacchi Berlin

The website and ordering system for Dhaka Kacchi, a Berlin-based kacchi
biriyani + borhani business. `src/` is the frontend (TanStack Start), `worker/`
is the ordering backend (Node.js + Postgres). See [CLAUDE.md](./CLAUDE.md) for
the full project context and architecture.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
